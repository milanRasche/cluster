# Cluster Project (Abandoned)

Another abandoned uni project. This one was mainly a project designed as a way to learn and get familiar with K8S and the ideas of truly Continuous Development and Integration. 

The project was meant to be somthing similar to GIMPS with users voulentarily contributing computer resources to solve some kind of math problem / challenge however its never got remotely close to that as being able to demonstrate full fleged CI/CD was the goal of the Semester.

Its desiged around a Microservice Architecture, with Services deployed to DockerHub which would then be picked up by K8S running in Azure. This would then gradually roll out changes and verify uptime and other statistics to ensure functionality.

Overall an interesting learning experience and deffinetly got a lot more confident with Docker, Azure, K8S and just the CI/CD pipeline as a whole.
